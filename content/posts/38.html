소개

제조업에서 프로세스 혁신(PI)과 데이터 엔지니어링을 하고 있습니다. 일하는 방식의 비효율을 찾아 개선을 기획하고, 기획한 과제의 파일럿 시스템은 직접 만들어 효과부터 확인합니다.

걸어온 길

  • 플랜트 사업관리 — 해외 현장 근무를 포함해 발전 플랜트 프로젝트를 관리했습니다. 반복되는 수작업과 비효율을 보며 데이터와 개발에 관심을 갖게 됐습니다.
  • 데이터 분석·ML — Python으로 현업 데이터를 분석하고 머신러닝 모델을 만들어, 웹 서비스로 붙여 실제 업무에 쓰이게 했습니다.
  • PI·파일럿 개발 — As-is/To-be 분석으로 과제를 기획하고, 로우코드(Mendix)와 Python으로 파일럿 시스템을 개발·운영하고 있습니다.

주로 쓰는 것

  • Python (Flask, Django, pandas, scikit-learn)
  • SQL, 데이터 모델링, BI (Qlik Sense, Power BI)
  • Mendix, Kubernetes, AWS 데이터 서비스

실무에서 부딪힌 문제와 해결 과정, 자격증 공부 기록, 투자 메모를 남깁니다. 회사와 시스템은 특정되지 않도록 각색해서 씁니다.
